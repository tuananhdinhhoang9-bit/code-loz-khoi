# Phase 11 — Monitoring, alert and cost on Azure
Implement **only phase 11**. Read `docs/COST_MONITORING.md` (archived GCP version, for the metric list), `docs/AZURE_ARCHITECTURE.md`; use `$cloud-budget-guard`. Azure Monitor dashboard or workbook: processing duration, queue age, output bytes, egress estimate, cost per clip. One actionable alert tied to the failure drill: condition, evaluation window, observed delay, first recovery action. Request and job IDs correlated across API and job logs; no credentials, SAS URLs or private content in logs. Workload-based monthly estimate (region, tiers, runtime hours, storage, requests, backups, egress) from prices looked up at the time and from measured durations, with the source and date. A budget alert is not a spending cap: say so.
