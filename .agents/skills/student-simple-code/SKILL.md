# Workflow
1. Read `AGENTS.md` and current phase requirements. Build only the minimum real implementation needed.
2. Prefer straightforward functions, a few modules, SQLAlchemy models, Jinja, plain JavaScript. No unnecessary base classes, repositories, dependency injection frameworks, microservices or speculative optimization.
3. Explain unusual concurrency/reliability code in 1–2 comments where useful; don't add comments to trivial statements.
4. Use recognizable variable names and error handling, avoid silent exception swallowing. Write tests around boundaries and failures.
5. Return concise output: changes, commands run, actual results, blocker and next phase. Don't claim something runs without testing it.
